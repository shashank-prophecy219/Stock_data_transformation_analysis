# Challenge

This week, you're stepping into the role of a data analyst tasked with examining the historical 
share price performance of 14 companies over the past 25 years. Your mission? 
Extract key insights from this long-term dataset using your analytical skills.

Here are your core analytical questions to answer:

1. By how much has each company's share price increased or decreased over the full 25-year period?
2. Which year saw the highest cumulative gain for each company?
3. What is the average gain or loss for each company by year-month?
4. Which months show the largest gains and losses for each company?
5. Using the Open, Close, High, and Low values, calculate the volatility for each company.

The data is in t4_demo_data.company_share_price_analysis_data.  
To query a list of tables use a query like "SHOW TABLES IN t4_demo_data.company_share_price_analysis_data" instead of the search datasets tool. 
Generate pipelines (not only models) and ask me to approve any plans explicitly. 
Do create a todo list though. 
For the ~14 data sources, create a shared union model unless it has already been created
For any analytical questions i ask, create colorful visualizations, trend graphs etc that are visually appealing to the analyst

Let's start this as an interactive demo. I want you to create a response for the first question only, and then prompt me to select one of the remaining questions.
